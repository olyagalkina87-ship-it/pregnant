# Семейный компас

Интерактивный прототип мобильного приложения аналитического центра **«Центр семейной аналитики»**. Сервис помогает парам, которые планируют ребёнка или уже ждут его, посчитать бюджет родительства, узнать о мерах поддержки в своём регионе и не пропустить сроки документов и выплат.

> **Важно.** Это учебный прототип. Все суммы, сроки, цены и шаблоны заявлений условные. Диалог с ИИ-помощником и голосовой ввод имитируются заготовленными правилами. Прототип не даёт юридических, финансовых или медицинских рекомендаций.

![Экраны прототипа](docs/screens.png)

## Что внутри продукта

| Часть | Доступ | Что делает |
|---|---|---|
| Меры поддержки региона | бесплатно | справочник мер: размер, уровень, кому положена |
| Бюджет родительства | бесплатно | средние расходы по этапам и сценариям (экономный, средний, комфортный), список «что купить и сколько стоит» |
| Рейтинг регионов «Где семье легче» | бесплатно | доля расходов на ребёнка, которую покрывают выплаты региона |
| Личный расчёт и план | платно (в демо 2 500 ₽ разово) | рассказ помощнику, помесячный бюджет, бюджетный разрыв, положенные меры, проверка сценариев, план для скачивания |
| Семья в курсе | платно (в демо 300 ₽ в месяц) | календарь по этапам от планирования до сада, число дней до срока, напоминания о покупках, документах и окончании выплат |

Особенности прототипа:
- выбор региона в начале;
- режим «пока только планируем»: помощник строит предполагаемый срок и календарь с этапа планирования;
- два родителя: у мамы и папы отдельные меры и документы, учитывается тип занятости (трудовой договор, ИП, самозанятость);
- чат с ИИ-помощником: текст или голос (в демо имитируется);
- шаблоны заявлений и окна подачи документов;
- светлая и тёмная тема.

## Как запустить

Откройте файл `index.html` в браузере. Сборка и сервер не нужны: это одна страница на HTML, CSS и JavaScript без зависимостей (шрифт Onest подключается с Google Fonts, без него используется системный).

## Как разместить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту-две страница будет доступна по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Структура репозитория

## Как устроен ИИ-помощник в рабочей версии

Помощник ведёт разговор, заполняет анкету и объясняет результат простым языком. Суммы выплат и право на меры считает отдельная программа по правилам из законов, а ответы помощника опираются только на справочник мер с источниками и датами проверки. В прототипе вместо ИИ работают простые правила разбора текста.

## Что нужно доделать для рабочей версии

- справочник мер с источниками и датами проверки для выбранных регионов, проверка юристом;
- программа расчёта пособий и декретных по нормативным актам;
- подключение ИИ к анкете и объяснению результатов с проверкой ответов;
- оплата, личный кабинет, хранение данных с согласием пользователя;
- настоящее скачивание плана в PDF и уведомления.
